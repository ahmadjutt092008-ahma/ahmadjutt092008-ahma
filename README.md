## ✅ How I work

1. **Safety rules first:** what the AI must never do, written before anything else
2. **Real data only:** real slots, real prices, the business's own answers. Nothing invented
3. **Humans approve:** emails become drafts and risky cases go to a person
4. **Test like a customer:** booking, cancelling, emergencies, edge cases
5. **Clean handover:** notes inside the workflow and a short guide for the team
